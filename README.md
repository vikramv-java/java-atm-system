# Java ATM System

A simple console-based ATM application built using Java.

## Features
- PIN Authentication
- Check Balancee
- Deposit Money
- Withdraw Money
- Menu Driven Program
- Object-Oriented Programming

## Technologies Used
- Java
- OOP Concepts
- Scanner Class

## How to Run

1. Compile the program:
```bash
javac ATM.java
```
2. Run the Program

```bash
java ATM.java
